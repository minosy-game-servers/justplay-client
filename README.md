# JustPlay Client

Download [JustPlaySetup.exe](https://github.com/minosy-game-servers/justplay-client/releases/latest/download/JustPlaySetup.exe) from the latest release, run it, choose an installation folder, then select your GTA V Legacy folder in launcher settings.

This repository contains release binaries and documentation only. The launcher checks for updates automatically. Russian and English are supported; other system languages fall back to English. GTA V is required and is not included.

Скачайте установщик из последнего релиза, запустите его и выберите папку установки. После установки укажите папку GTA V Legacy в настройках лаунчера. Обновления проверяются автоматически. Игра GTA V в комплект не входит.
